# Khabit Finance in Rust

A public learning project for building a personal and family finance backend in Rust.

The goal is to learn Rust deeply by implementing a real-world finance domain from scratch instead of following isolated language exercises.

The project will gradually cover:

- Accounts and balances
- Income and expenses
- Categories and subcategories
- Budgets
- Transfers
- Credit cards and statements
- Savings goals
- Investments
- Planned and executed transactions
- Period closing
- Financial dashboards
- Annual summaries and reporting

The learning path is intentionally incremental. Each new finance capability introduces a small set of Rust concepts, including:

- Cargo, packages, crates, and modules
- Structs and enums
- Ownership and borrowing
- References and lifetimes
- `Option` and `Result`
- Pattern matching
- Traits and generics
- Domain modeling
- Error handling
- Collections and iterators
- Testing
- Async Rust
- PostgreSQL persistence
- Database transactions
- HTTP APIs
- Production-oriented Rust practices

The project emphasizes strong domain modeling and using Rust's type system to prevent invalid financial states whenever possible.

## Learning rule

All production code is written manually as part of the learning process.

AI may be used as a mentor to explain Rust concepts, review code, diagnose compiler errors, discuss architecture, and provide guidance, but not to implement the production code.

The final objective is a strongly typed, well-tested, production-ready finance backend and a solid practical understanding of Rust.
